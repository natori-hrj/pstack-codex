# nstack v0.4.1 — Legacy Python Cleanup

[English](v0.4.1.md)

- 配布、インストール、自動実行、品質ゲートを Go 実装と共通 Markdown 資産に統一しました。nstack の開発・テスト・実行に Python と PyYAML は不要です。旧実装と比較テストは [v0.4.0 タグ](https://github.com/natori-hrj/nstack/tree/v0.4.0)に残ります。
- レビュー予算、承認、保護 ref、配信、ロールとプロトコル、証跡、キャンセル、スナップショットの切り戻しを Go の契約テストで確認します。実 Codex のオフライン探索・サンドボックス検証と認証済みモデルの検証は別に実行します。
- Codex の Workflow Support と Native Automation、OpenCode v2 の Workflow Support を維持します。OpenCode の Native Automation、並列書き込み隔離、ネイティブスキーマ強制は未対応です。[OpenCode #12](https://github.com/natori-hrj/nstack/issues/12)、[Claude Code #13](https://github.com/natori-hrj/nstack/issues/13)、[Grok Build #14](https://github.com/natori-hrj/nstack/issues/14) は引き続き対応課題です。
- 旧スナップショットを保持し、切り戻し時は v0.4.1 で以前の ID を有効化します。v0.4.0 と旧 Python 版の形式を扱えます。[移行と切り戻し](../migration.ja.md)を参照してください。

## 配布物

承認済みソースから Go 1.27.4 を使って [再現ビルド](../../README.md#standalone-go-binary)を実行します。別のソース配置で両バイナリを再ビルドして比較し、`SHA256SUMS` を照合します。Linux amd64 は実行検証対象で、Linux arm64 はクロスビルドです。

`nstack-linux-amd64`、`nstack-linux-arm64`、`SHA256SUMS`、`LICENSE`、`LICENSE-upstream`、および [TOML ライセンス](../../vendor/github.com/BurntSushi/toml/COPYING)・[YAML ライセンス](../../vendor/go.yaml.in/yaml/v3/LICENSE)・[YAML 通知](../../vendor/go.yaml.in/yaml/v3/NOTICE)をそれぞれ異なるファイル名で用意します。Git、ハーネス、ユーザー指定の品質ゲートコマンドは別途必要です。
