# nstack v0.4.1 — Legacy Python Cleanup

[日本語](v0.4.1.ja.md)

- The Go implementation and shared Markdown assets now cover the distribution, installer, automation and quality gates. Python and PyYAML are no longer needed to develop, test or use nstack. The historical implementation and comparison suite remain in the [v0.4.0 tag](https://github.com/natori-hrj/nstack/tree/v0.4.0).
- Go contract tests cover review budgets, authorization, protected refs, delivery, role and protocol checks, evidence, cancellation, and snapshot rollback. Real offline Codex discovery and sandbox checks run separately from authenticated model tests.
- Codex retains Workflow Support and Native Automation. OpenCode v2 retains Workflow Support; Native Automation, parallel write isolation and native schema enforcement are unavailable. The Native Adapter work for [OpenCode #12](https://github.com/natori-hrj/nstack/issues/12), [Claude Code #13](https://github.com/natori-hrj/nstack/issues/13) and [Grok Build #14](https://github.com/natori-hrj/nstack/issues/14) remains open.
- Keep previous snapshots and use the v0.4.1 installer to activate an earlier ID. It supports both v0.4.0 Go snapshots and the legacy Python layout. See [migration and rollback](../migration.md).

## Distribution

Build from the approved source with Go 1.27.4 using the [reproducible build commands](../../README.md#standalone-go-binary). Compare both binaries against an independent build and verify `SHA256SUMS`. Linux amd64 is the execution target; Linux arm64 is cross-built.

Prepare `nstack-linux-amd64`, `nstack-linux-arm64`, `SHA256SUMS`, `LICENSE`, `LICENSE-upstream`, and the [TOML license](../../vendor/github.com/BurntSushi/toml/COPYING), [YAML license](../../vendor/go.yaml.in/yaml/v3/LICENSE) and [YAML notice](../../vendor/go.yaml.in/yaml/v3/NOTICE) with distinct filenames. Git, the harness and any user-specified quality-gate programs remain external tools.
